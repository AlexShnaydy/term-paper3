# term-paper3
# Влияние корпусных метрик на замечаемость и исправляемость лексических ошибок

Репозиторий содержит код для курсовой работы. Данные анонимизированы и включены в репозиторий.

## Содержимое

| Файл | Описание |
|------|----------|
| `analysis.R` | Полный статистический анализ в R: регрессии (glmer), корреляции Спирмена, расчёт энтропии Шеннона, визуализация.|
| `yandexgpt.ipynb` | Google Colab для отправки запросов к YandexGPT 5.1 Pro.|
| `semantics.py` | Расчёт косинусной близости между векторами слов (модель `ruscorpora_upos_cbow_300_20_2019`, `gensim`) |
| `data/` | Анонимизированные CSV-файлы: `R_sentences.csv` (32 предложения с метриками), `R_human.csv` (ответы людей), `R_model.csv` (ответы модели) |
